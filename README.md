# NOVA - Responsive Landing Page

## Elevate Labs Web Development Internship - Task 1

A clean and responsive landing page built using HTML5 and CSS3.

## Project Overview

NOVA is a modern digital solutions landing page created as part of
Task 1 of the Elevate Labs Web Development Internship.

The website focuses on responsive design, clean layout, modern UI,
and accessibility-friendly semantic HTML structure.

## Features

- Responsive navigation header
- Hero section with call-to-action buttons
- Services section
- About section
- Statistics section
- Responsive footer
- Social media links
- CSS Flexbox
- CSS Grid
- CSS Media Queries
- Hover effects
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- VS Code
- Google Chrome
- Live Server

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. View the website in your browser.
5. Resize the browser window to test responsiveness.
